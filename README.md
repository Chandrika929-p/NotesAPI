# 📝 NotesAPI

A full-stack Notes Management application built using **FastAPI, SQLAlchemy, SQLite, HTML, CSS, and JavaScript**.

The project provides REST APIs for managing notes along with a simple and interactive web frontend.

---

## ✨ Features

- Create a new note
- View all notes
- Get a note by ID
- Search notes by title
- Update notes
- Partially update notes
- Delete notes
- Delete confirmation
- Interactive frontend
- SQLite database
- SQLAlchemy ORM
- Pydantic request validation
- FastAPI automatic API documentation

---

## 🛠️ Tech Stack
